# archLoop GUI Prototype

This directory contains a static, Codex-inspired GUI prototype for archLoop.
It is intended for product review and visual iteration before any backend or CLI
integration work.

Open `index.html` directly in a browser:

```bash
open gui/index.html
```

The prototype is self-contained and does not require a dev server. It includes
sample Hub run state, a transcript, a checklist, terminal/event/patch tabs, and
inspector actions for merge approval and task recovery.

The generated design concept used for implementation review is saved at
`gui/assets/archloop-gui-concept.png`.
