Configuration is now split by scope:

- [Configuration and paths](/docs/reference/configuration) explains shared Hub,
  project, repository, and legacy repo-local settings.
- [Environment and authentication](/docs/reference/environment-and-auth)
  explains credentials and login sessions.
- [Legacy repo-local setup](/docs/guides/legacy-repo-local-setup) explains
  `.archloop/` custom scaffolds.

Hub projects do not require `.archloop/` or a repo-local `config.json`.
