archLoop combines a project Hub, a local task board, agent roles, sandboxed
execution, and Git branch workflows. Start with the CLI for a complete workflow
or use the TypeScript API to build a custom one.

## Recommended workflow

```bash
npm install --save-dev @yibeibankaishui/archloop
npx archloop initialize
npx archloop project add
npx archloop check
npx archloop run --flow with-review
```

`archloop initialize` configures the shared Hub. `project add` registers an
existing Git repository. `check` verifies Hub and project readiness. The final
command implements ready tasks, reviews their branches, verifies them, and
merges eligible changes.

## Two supported paths

### Hub workflow

Use Hub for new projects. It lets you select and operate on registered projects
from any directory, shares agent and authentication configuration, and supports
task-board flows and recovery.

### Legacy repo-local workflow

`archloop init` creates a `.archloop/` scaffold inside one repository. It remains
supported for existing custom orchestration scripts, but it is not the default
onboarding path.
