## What is archLoop?

archLoop is a TypeScript CLI tool that orchestrates AI coding agents inside isolated sandbox environments. It manages the full lifecycle of running an agent against your codebase: syncing code into a sandbox, invoking the agent, and syncing changes back.

## Key Concepts

- **Sandbox** -- An isolated environment (Docker container or local directory) where an agent executes code
- **Host** -- Your machine where archLoop runs and the real git repo lives
- **Agent** -- The AI coding tool invoked inside the sandbox (e.g. Claude Code)
- **Iteration** -- A single invocation of the agent, producing at most one commit

## Quick Start

### 1. Install

```bash
npm install -g archloop
```

### 2. Initialize

Run `archloop init` in your repository to scaffold the config directory:

```bash
archloop init
```

This creates a `.archloop/` directory with a Dockerfile, prompt file, and configuration.

### 3. Run

```bash
archloop run
```

archLoop will build the Docker image, sync your code into the sandbox, and start the agent.
