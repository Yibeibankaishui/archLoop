---
title: Core concepts
description: Understand the user-visible concepts behind archLoop workflows.
---

| Concept    | Meaning                                                                            |
| ---------- | ---------------------------------------------------------------------------------- |
| Hub        | Shared user-level configuration, registered projects, roles, auth, and run records |
| Project    | A registered Git repository with a stable Hub identity                             |
| Task       | A local Beads work item projected into an archLoop collaboration status            |
| Flow       | A predefined sequence such as implementation, review, verification, and merge      |
| Agent role | A named workflow stage mapped to a provider, model, and options                    |
| Sandbox    | The environment in which an agent runs                                             |
| Worktree   | A Git checkout used to isolate branch changes from the source checkout             |

Read the focused pages for lifecycle and ownership rules:

- [Hub and projects](/docs/concepts/hub-and-projects)
- [Tasks and flows](/docs/concepts/tasks-and-flows)
- [Sandboxes and worktrees](/docs/concepts/sandboxes-and-worktrees)
