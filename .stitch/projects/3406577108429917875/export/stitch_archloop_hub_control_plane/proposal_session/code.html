READY_FOR_EXTRACTION

The objective is to migrate our legacy JWT-based authentication system to a unified OAuth2 flow using the internal identity provider.

Functional Requirements

  • 01. Must implement PKCE flow for all mobile clients to ensure high security during the token exchange phase.
  • 02. The backend middleware should be updated to validate tokens against the /introspection endpoint instead of local public keys.
  • 03. All existing user sessions must remain valid during the 24-hour transition window to avoid downtime.
